Why this matters now

A real example from this month: “PHP2Shell”

PHP is the behind-the-scenes software that powers a huge number of online stores, including WooCommerce, WordPress, Magento and Shopware. In October 2026, two serious security holes were found in PHP itself.

Patched on 21 Oct 2026Two flaws (CVE-2026-109618 and CVE-2026-109619), each rated 9.2 out of 10 for severity, got a fix from the PHP team.
Very wide reachThey affect PHP going back to version 5.4, so the software behind many stores, even when a store's own code is perfectly clean.
Not fixed by plugin updatesUpdating your store's plugins won't fix this. The PHP software on the server has to be updated.

Early attack attempts were reported before the fix was public, and researchers have since shown working code execution against test servers. At the same time, security firm Sansec notes that attacks need specific conditions to work, so this isn't a reason to panic. It is a good reason to make sure someone is on top of it.

This is exactly the kind of moment CyberWall exists for. Our team notices news like this early, works out what it means for your type of store, tests the fix on a private copy first, checks that checkout still works, and then helps get it onto your live store, with a plain-English note so you know what happened.

Sources: Sansec Forensics Team, “PHP2Shell: PHP RCE (CVE-2026-109618, CVE-2026-109619)”, 21 Oct 2026 (sansec.io); reporting from SecurityWeek; US CISA vulnerability notices; and the PHP project's own release announcement (PHP Foundation / php.net). A “CVE” is just the public ID number given to a known security hole.

How it works

Four simple steps

You don't need to understand the technical side. Here's what happens.

  1. Connect your site

    We do a one-time health check and set things up with you, step by step.

  2. We watch

    Our team follows new security news every day and works out what matters for your store.

  3. We test on a copy

    Fixes are tried on a private copy first, including a test of your checkout.

  4. We fix and tell you

    We update your live store and send you a short, plain-English note.
